# Targeted Mac native runtime repair

The approved Python/adapter pilot could not use a rebuildable Mac producer. The first actual failure was an inherited Command Line Tools SDK built with Swift 6.4 being selected by Xcode Swift 6.3.3. With the installed Xcode 26.5 SDK selected for the build process, compilation exposed missing native source files and an incomplete explicit-capture API integration.

This change restores the existing native observation modules and their matching request/bundle, source initializer and descriptor-backed epoch interfaces. It retains explicit-window validation, image/source hashes and pinned-directory behavior. The native context implementation also receives the small compiler-required optional/CFDictionary/mutable-collector corrections. Measured ellipsis components come from the existing native pixel detector on the retained image. The date formatter is computed because its former stored initialization occurred after terminal command dispatch.

The project pilot gets a separate native authority route. It checks the project profile, task/owner/session/surface, contract and pinned interpreter/dependencies, running producer path/hash, and delegates to the unchanged complete project-authority validation through the new read-only `native_authorize` CLI operation. That check uses the existing `gui_observe` authority requirements, including independent review and live foreground consent, without reserving input, initializing a ledger, acquiring a writer, or observing LINE. A version rename alone cannot authorize anything. The legacy grant2 branch retains its frozen task/contract checks.

`mac_runtime.mjs` is the bounded hosted entry. It assembles the genuine CUA binding, native before/after context, ScreenCaptureKit support, existing classifier/chooser algorithms, current-frame menu/scroll/back locators, native window lineage, retained screenshot/AX bytes, CLI bridge, filesystem observer and pinned decoder. Chooser targeting uses a unique current hosted settable-field index, rather than dispatching a separately enumerated native AX index. The initial empty-destination baseline is obtained from the actual prepare result; the existing pre-confirmation refresh and validators remain in force. No observation record or provider-shaped fixture is generated during preparation.
