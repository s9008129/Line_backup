# 完整盤點：必備能力

目標：在下載前知道列表共有幾本、每本的處理狀態，以及哪些本要下載。由 Agent 使用既有原生 Computer Use 瀏覽及判讀，不新增捲動控制器。文件規範不是已完成實機驗證的證明。

## 使用邊界

- Owner 人工開啟指定相簿列表並交接前景。當次列表就是對象，不用群組名稱／中文 OCR 搜尋、選擇或核准群組。
- `INVENTORY_ONLY` 僅觀察、列表捲動及保存本地盤點紀錄。核對同日期同張數的歧義候選若需要開詳細頁，須在當次一般導覽授權內，否則先問；不開下載選單、不執行 Save All、不修改照片／完成事實。
- Skill 審查模式不取得前景。下載需要另外符合當次 BACKUP／RESUME 範圍與仍適用的資料保護條件。
- 接續任務沿用 Owner 指定目的地的既有紀錄，以新畫面和卡片脈絡核對。若發現可能是另一列表，停止並問 Owner，不依名稱猜配，也不自動啟動另一群組任務。

## 原生捲動方法

沿用 [重疊捲動方法](verified-experience.md)：在已確認的相簿列表捲動，一次動作後立即重新觀察，保留相鄰畫面的共同卡片。四分之一可視高度已有成功操作經驗；每次仍依當下畫面核對位移與重疊，不沿用舊位置。

在本 Session 的 CUA 文件明確提供 macOS `App.scroll(target, direction, pages)` 時，可用以下呼叫形狀；`listTarget` 必須來自最新 AX 的列表元素或已確認座標基準下的安全列表區域：

```javascript
await lineApp.scroll(listTarget, "down", 0.25);
await lineApp.getAXState();
await lineApp.getScreenshot();
```

`lineApp`、`listTarget` 是當次實際觀察建立的變數，不能直接照抄舊元素編號或座標。不同平台的參數可能不同，先讀本次工具文件。取得 app 可能啟動程式，Owner 尚未人工開啟／交接時，不藉此代替交接。

- 每次只捲一次，觀察後才決定下一步；不連續盲捲、猜跳底端或以捲動次數推算總本數。
- 過期 AX ID 先重新取得；座標基準不明就停。選單、下載視窗、對話框或編輯欄位占用列表時不捲動。
- 無位移先分辨是否真到邊界、工具未生效或內容尚未載入，不能把工具失效當底端。
- 這是一般 L1 盤點，不冒充正式 G2 驗收；若當次要求 G2，仍保留它的原始完整證據要求。

## 從頭到尾列清單

1. **建立起點。** 觀察當前列表；不在頂端時，朝上小幅捲動並逐次觀察。以頂端邊界及同一首卡再次向上無位移交叉確認；沒有可靠起點就記盤點未完成。
2. **記錄每張卡片。** 依列表順序給本次流水號，記日期範圍、預期張數、封面／鄰接／詳細頁等可區分的視覺依據及觀察來源。名稱僅作可選註記，不作身分依據。日期和張數相同不能直接合併。
3. **有序重疊。** 下一畫面必須與上一畫面共享可確認為同一張的卡片，且前頁末段與後頁首段順序一致。部分可見卡片先保留待確認，不漏記，也不直接算成新一本。
4. **修補缺頁。** 捲太多而失去重疊時，保留缺頁紀錄，以較小步距向回核對，接回最後已證明的畫面；仍不能接回則重建本輪盤點或停止。不能因「看起來差不多」拼接清單。
5. **確認底端。** 末頁載入穩定後，再向下小幅捲動；同一末卡、同一列表、卡片次序及可靠位置／視覺位移均不變，才支持已到底。一次無變化但原因不明不能證明到底。
6. **逐本對帳。** 與該列表已確認的歷史完成、人工備份、排除與中斷紀錄比對，保存逐本狀態與來源。舊紀錄不足先保護，不因缺少標記就重下。

任何列表重排、新增／刪除卡片、視窗切換或前景中斷，都先保存斷點。重新觀察後判斷能否證明同一列表連續性；無法證明就重新盤點，不把舊畫面游標當新的控制位置。

## 必須交付的清單

每本只能列入一個當前狀態：已完成、已排除、待下載、先前未完成、未知、受保護歷史。未完成與待下載分開，避免直接把中斷相簿排入一般新下載。

```text
總本數 = 已完成 + 已排除 + 待下載 + 先前未完成 + 未知 + 受保護歷史
```

保存盤點時間、當次列表／任務本地識別、頂底與重疊證據索引、每本狀態及依序待下載清單。正式備份位置已指定時沿用其 backup-records；未指定時先保存本任務私有盤點草稿，目的地標「未指定」，不要猜路徑或因此初始化正式備份狀態。既有 `daily.py` 可協助記錄；它要求的歷史／目的地資料缺失時如實回報，不偽造輸入以取得 PASS。

只有頂底及中間覆蓋成立、無漏卡／重複／身份歧義且總數對上，才報「列表已完整盤點」。若仍有未知或受保護歷史，可以報已看到的總本數，但必須另外標示「可下載清單尚未對帳完成」，不可進入下載。新圖或改變張數須保留舊完成事實並另查差異。

先前未完成相簿進入相簿級恢復流程：確認前次已終止、派送結果明確並取得該本恢復授權後，再排入另一個新空白目錄。UNKNOWN 不自動重送。
