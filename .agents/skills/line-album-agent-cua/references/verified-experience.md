# 可重用的 LINE 操作方法

這裡保留會影響操作判斷的方法，不依賴審查編號、工作分支、舊座標、視窗編號或先前聊天。原始測試報告留在專案證據紀錄中；成功經驗不保證所有版本或工具都適用。

## 在列表中開啟正確相簿

以當下卡片的日期、張數、封面及相鄰卡片確認目標。點文字／日期區域開啟相簿，避開照片縮圖；進詳細頁後再核對日期、總張數及可區分的視覺內容。

日期及張數相同不代表同一本；中文名稱不作列表身分依據。開錯相簿就不開下載選單，安全返回後重新定位。AX 編號過期時重新觀察，不用舊編號或原位置繼續點。

## 以重疊畫面捲動

先確認目標是相簿列表，再以原生 Computer Use 小幅捲動；四分之一可視高度已有成功經驗。每次動作後觀察新畫面／AX，確認確實移動，且前頁末段與後頁首段保留可識別的共同卡片。

缺少重疊就縮小步距並補回缺頁；不能用多次盲捲、AX row 數或舊 scrollbar 數值推算完整性。頂端、底端及逐本清單的完整流程見 [完整盤點](inventory.md)。

## 找到真正的儲存全部選單

以最新詳細頁辨識右上選單，開啟一次後重新觀察，確認唯一「儲存全部」與安全點位；不假定固定列次或舊座標。

選單可能是獨立 popup：主視窗截圖看不到，不代表選單沒開。過去曾以原生視窗清單、指定 popup 截圖及 OCR 成功確認選單；只有本 Session 已提供這些支援能力時才使用，先核對其文件與當前視窗。缺工具時回報觀察缺口，不連點、不猜 API，也不寫新的控制器掩蓋問題。

找不到 repo 裡某個 locator 函式，不等於 Agent 無法看畫面定位。先用現有工具判讀；只有真實、重複出現的缺口才評估最小輔助工具。

## 選擇儲存位置與驗證

每本使用新空白目錄；看到確定的資料夾選擇視窗後，用「前往資料夾」輸入完整絕對路徑，觀察路徑及末層資料夾正確才確認一次。不靠 chooser 的上次位置或猜資料夾列座標。

下載後核對實際檔數、非空檔、穩定清單、逐檔 SHA-256 與 ImageIO 完整像素解碼，再保存完成紀錄並讀回。這套組合有真實成功經驗；檔案可解碼本身不證明與服務端原始檔完全相同。操作與工具細節見 [備份與恢復](backup-and-resume.md)。

## 取消與中斷的教訓

進度畫面可能落後實際檔案寫入。曾在畫面仍顯示部分進度時按取消，事後卻已取得整本可解碼檔案。因此「點了取消、視窗關閉」不能獨自證明已停止或只下載一部分，也不能據此宣稱原生續傳成功。

每次查實際目的地、操作事件及 LINE 狀態；有完整檔案就先驗證，不重下。下載結果未知就保留 UNKNOWN，不因舊 intent 計數仍為零而忽略實際已派送事件。

目前採相簿級恢復：已完成的跳過；確定停止且未完成的一本，取得該本恢復授權後才下載到另一個新空白目錄。原目錄全數保留。LINE 原生只補缺檔尚未實證，不作日常能力承諾。

## 判斷下一步

- 目標、授權、前景與操作結果清楚：用當前工具完成下一個必要動作。
- 只是畫面或 AX 改變：重新觀察並定位，不先建立新框架。
- 身分不明、前景中斷、目的地不符、可能覆寫或派送結果未知：停止相關動作，保存事實並用白話提出最小問題。

歷史實測成功、當次 Agent 觀察、檔案驗證與正式獨立驗收分開報告；未執行的項目不寫成成功。
