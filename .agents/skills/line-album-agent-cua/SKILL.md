# LINE 相簿備份

由 AI Agent 判讀畫面、選擇下一步，Computer Use 執行輸入；提示詞啟動，必要小工具協助記錄與驗證。不新增控制器或授權框架。

## 日常預設

預設完成指定列表所有尚未備份、未排除的相簿。每次啟動都自動檢查前次任務：有進度就接續，沒有才開始新任務；不要求使用者選模式、填 MODE／RESUME 或提示「接續」。完整盤點是備份中的必要步驟，不是另外一個使用者模式。

只有使用者明確要求審查／優化 Skill 時才只做文件與離線檢查，不啟動或操作 LINE。討論提示詞不是提交備份任務；只有實際任務授權及前景交接才允許 GUI 輸入。

## Agent 的決策責任

將任務理解為「完成這份列表的合格備份」，不是等使用者逐步下令點按鈕。從本次及仍有效的前文整理目標列表、目的地、下載／恢復授權與禁止事項，保存真實來源。已授權備份整份列表到新目錄時，原生「儲存全部」就是任務中的下載動作；不要求使用者另說特定口令，也不在每本前重新請示。

每次輸入前分別判斷：**允許做什麼、現在看到什麼、工具能可靠操作哪個目標、前次是否可能已送出**。缺少 popup 畫面是觀察問題，不能報成缺少下載授權；點擊結果未知則是查證問題，不能再點。沿用原授權做可逆導覽與觀察，直到下一步可可靠操作，或有具體且自行無法解決的阻塞。

導覽依 [入口與實機操作方法](references/verified-experience.md)：以當次畫面確認頁面、焦點、控制項作用及預期結果；每次輸入後重新觀察。已核對合格詳細頁且盤點有效時直接進 Save All，不為返回而返回；未知入口沒有可靠返回依據就保留原視窗，先唯讀查證，不猜 Escape／Command-W／關閉。前景中斷停止所有 GUI 輸入。

主要入口是 Owner 先開好指定列表，再提交使用手冊的正式 Prompt，該次提交同時授權並交接前景；不等待第二則開始指令。保存實際提交的任務與交接來源於本機私有證據，不能用範本、Issue 或工具回傳值冒充同意。前景中斷後須重新交接，但不要求重複已有效的備份授權；重新交接也不解除未知派送。

**自適應是方法調整，不是擴張權限。** 可在同一列表內重新觀察、改用當次文件支援且允許的觀察來源、重驗座標映射、縮小捲動步距、補接缺頁或更新盤點，再依實際狀態驗證／恢復。不可猜 API、沿用失效座標、改下載入口、跨列表、修改程式／紀錄規則或繞過拒絕。每次查證須帶來新資訊；同一根因最多三次有證據嘗試，連續兩次沒有新資訊就停止相同方法，不靠盲目重試繼續。

`Line_backup` 是唯一核心目錄。日常記憶來自本專案的結構化 JSON 與實際照片；開發歷程留在 Git，不作為啟動或接續的依據。命名與校正流程使用 `daily` 的直接參數入口，Agent 自行從 `memory` 取得 `album_key` 並保存證據，不要求 Owner 手填 JSON。

預設備份位置是**目前本 Skill 所在專案根目錄的 `backup/`**；此工作區目前為 `/Users/hsiaojohnny/dev/Line_backup/backup`。先由當前專案根目錄計算實際路徑，不依賴舊的絕對路徑；使用者指定其他專案內位置時依其指示。預設位置不是新任務或重下載的許可，仍須先核對前次任務及其紀錄。

## 工作流程

1. **自動找回前次任務。** 讀本專案 `.local/line-backup/active-task.json` 指向的 `backup-records`，以 `daily memory` 讀取逐本身分、狀態、操作與結構化歷史提示，再核對目的地照片。依 [啟動與自動接續](references/backup-and-resume.md) 判斷前次已完成、仍在下載、待驗證、已中斷或未知；不用使用者提供接續參數。入口指向舊專案位置、目錄身分不符或工具拒絕時，保留原件並停止接續，不改索引、紀錄或初始化空帳；專案搬移需另行安全對帳。歷史提示只保護可能相符項目，不跨列表認領完成；開發資料是否存在不影響日常接續。
2. **接受人工交接並判定入口。** 依當次 [入口與導覽條件](references/verified-experience.md) 核對同一連續列表及前景；名稱不能代替證據，也不用群組名稱或中文 OCR 搜尋／改配。未指定位置時使用目前專案的 backup/，接續仍核對原位置綁定；名稱只作顯示與目錄，完全讀不到才問。入口有據就自主前進，無據先唯讀查證，仍無法解決才請 Owner 處理一個具體事項。
3. **完整盤點並排程。** 只在已確認且連續的相簿列表盤點；入口或返回後的連續性不足，先依 [入口與導覽條件](references/verified-experience.md) 處理，不先下載。依 [盤點方法](references/inventory.md) 從頂到底，以相鄰畫面重疊避免漏卡，保存總本數、逐本狀態及有序下載清單。日期／張數相同仍須其他視覺依據；缺頁先小步回捲補接，仍有歧義才停下釐清。同一列表先以 `capture-group-name` 保存群組名稱一次；每一本經視覺身分確認後再以 `capture-album-name` 保存相簿名稱。名稱不參與 dedupe 或歷史合併。接續時核對已保存清單與當下列表，同 Session 內容有變或覆蓋不足才重建；新 Session 依工具要求開新 scan，以原清單協助對帳，不沿用舊座標或畫面游標。盤點及對帳完成後，自動繼續下載。
4. **逐本下載及驗證。** 依 [單一 Save All 流程](references/backup-and-resume.md#開啟相簿與儲存全部) 處理資格、detail／intent 讀回、一次開選單、popup 觀察與映射、一次派送及 chooser。唯一下載入口是 `⋯ → 儲存全部`；`選擇項目`、單張或逐張下載均不可替代。下載後以 direct `outcome` 記錄第一個已知結果，再以 direct `verify --attempt-id` 完成持久改名交易，逐檔核對數量、SHA-256 及 ImageIO 完整解碼，保存完成紀錄並讀回。命名中斷用 `resume-naming`，不重送。完成事件與檔案讀回成功後，依同一入口與導覽條件確認可靠返回入口；有據才返回原列表並以新畫面定位下一本，無據就保留原視窗並回報入口缺口，不猜 Escape／Command-W／關閉，重複至待辦為零。
5. **結束對帳。** 總本數須等於「已完成＋已排除＋待下載＋先前未完成＋未知＋受保護歷史」。只有已完成及排除以外均為零，且列表覆蓋證據完整，才回報這次列表全部處理完成。列表內容有變先更新盤點，不覆寫舊完成事實。

## 保護資料與接續

- 已完成、已人工備份及已排除的不重下載；證據不足的舊資料先保護並查證。完整盤點且無身分歧義後，可跳過個別歷史受保護項並繼續其他已核對合格項；受保護項不升格為完成／排除。活動下載、未解派送或命名交易須先處理，不以跳過解鎖其他下載。
- 新備份直接使用相簿資料夾及 `<相簿>_001.<ext>`；名稱只供顯示。舊 `albums/<UUID>` 與既有照片保留，不遷移、不因名稱相同認領。
- 既有 `GROUPED_V1` 名稱錯字使用 CLI 校正，不在 Finder 手改。相簿校正同步資料夾與照片前綴；群組校正涵蓋所有已完成新格式相簿。兩者都要求群組子目錄與相簿內檔案集合精確相符，遇到未完成、未知、舊格式／外來項目、額外檔案、symlink 或檔案漂移就拒絕。`FLAT_V1` 暫不支援名稱校正，保留紀錄並回報限制。
- 一次只處理一本。結果未知不重送；舊計數為零不能推翻實際已派送事件。
- **自動相簿級恢復：**任務初始授權涵蓋確認中斷後的恢復時，Agent 確認前次已停止且未完成、保留原檔，自行在另一個新空白目錄恢復該本，不逐本要求使用者重下接續指令。已完成的一律跳過；原授權不含恢復或結果無法釐清時才問。不承諾 LINE 能只補缺檔。
- 不發訊息、刪除、分享或覆寫照片；不修改舊完成事實。儲存位置、身分、操作結果不明或工具拒絕時停下，不換入口繞過、偽造批准或重置紀錄。
- 主視窗看不到選單，依 [畫面觀察與定位](references/visual-grounding.md) 查證其他當次可用畫面來源及座標映射；主視窗 AX 缺標籤不等於無法視覺定位。必要證據仍不足才回報能力缺口，不盲點、不用舊座標。

## 回報與參考

在「舊任務與入口核對完成、完整盤點完成、每本完成或遇阻、最終對帳」四個節點主動回報，不因回報等待追加開始指令。每次用白話列總本數、已完成、排除、待下載、先前未完成、未知、受保護歷史、已驗證張數、目前一本／阻塞及下一步；實測、文件規範與尚未測試的能力分開說。2026-10-30 已有特定 macOS CUA Session 四本／141 張的獨立 E2E PASS，涵蓋每本重新觀察 popup、共同錨點映射、chooser、命名及檔案／completion 驗證；不代表所有環境通用。跨 Session 恢復、名稱校正與跨模型遵循率仍未測。daily 的 `real_line_e2e=NOT_TESTED`、`sensor_verified=false` 是工具簿記能力聲明，不改寫成 GUI 驗收；實測來源見 [根因與 E2E 紀錄](../../../docs/LINE相簿SaveAll決策根因與E2E修正紀錄.md)。私人畫面、照片與原始檔名留本機；保存可接續的紀錄，不只依靠聊天記憶。

日常完成不是舊正式 AUTO 驗收，也不改歷史 VERIFIED。舊控制器與正式交易入口已退役。使用者啟動提示詞見 [使用手冊](../../../docs/LINE相簿備份_使用手冊.md)。

新任務預設使用 `FLAT_V1`，照片位置為 `backup/<相簿名稱>/`；群組名稱仍保存為顯示資訊，不建立群組資料夾。舊任務缺少 layout 欄位時維持 `GROUPED_V1`，既有資料不搬移。扁平布局目前不支援名稱校正，工具會以 `FLAT_NAME_CORRECTION_NOT_SUPPORTED` 拒絕；不可在 Finder 手改或改寫紀錄繞過。
