# 記事本 B1 操作判準與逐項接續修復計畫

## 目標與證據

以 Agent 驅動既有 Skill，自主核對當次畫面並接續同一記事本列表；不新增控制器、人工逐項判斷或日常啟動步驟。

既有故障報告顯示：第一項在短暫工具列消失後保留 UNKNOWN；另外六項未建立 intent，沒有 LINE 或 CLI 拒絕證據。當次 AX 無下載節點不等於充分視覺定位不存在；舊截圖是否具備完整映射仍未證明。hover 能力、工具列顯示條件與裝置識別漂移的因果尚未定案，不據此修改 CLI 或歷史。

本次針對可確認的操作指示歧義：視覺／AX 證據界限、「未播放」是否包含來源自動播放、局部 B1 阻塞後其他合格項的下一步，以及第二候選的新證據判準。文件修復不證明原下載已成功，也不保證所有環境可定位控制。

使用者指定的 Tester 經兩輪討論，撤回「只接受 AX/API」的過窄解讀；指定 Reviewer 對計畫給予附約束的 APPROVED。此為計畫審查，並非實作獨立驗收或真實 LINE E2E。

| 負責 | 寫入範圍 | 交付 |

兩個 Worker 在互斥檔案內平行修改。原始問題提報單、私人原件、帳本與照片不納入提交。

## 綁定約束

- 當次充分視覺證據可支持定位，無需虛構 AX 節點；仍須確認 viewer、控制可見／歸屬／啟用、座標空間與映射、來源及狀態有效。只見箭頭、舊座標或過期截圖不合格。
- 區分 Agent 播放輸入、來源播放狀態與來源／選取／幾何／映射漂移。Agent 不操控播放、不取證內容；來源自動播放本身不單獨阻擋，任何漂移或控制遮蔽仍停止，不為確認狀態新增操作。不追認舊 attempt。
- 第二候選只接受確實改變方法／映射的正面新內容。新文件存在、新 capture、重開、時間流逝、只換點與事後補 request 都不解鎖。保留 prior refs、隔離、額度、intent 與固定 slot。
- intent 前局部 B1 阻塞，保留該項未完成；只有無全域 blocker、前景有效、可靠返回契約成立，才可一次一項重新評估其他合格目標。未隔離 UNKNOWN／無 outcome、活動下載、pending naming、LOCAL_CHANGED、列表覆蓋／身分不明仍停止。
- 三份 reference 只同步純敘述並回連 B1；不修改可執行 helper、欄位、schema、CLI、hover API 或資料完整性規則，不重建退役框架。
- 本輪無日常前景交接，不操作 LINE、下載、私人帳本或照片，不把文件修復當成派送授權。

## 驗證與後續界線

執行 daily records、notes CLI help 與全部 notes 測試，保留實際命令、exit code 與測試數。行為案例覆蓋合法視覺定位、映射不足、自動播放與漂移、候選額度、跨 Session、局部／全域阻塞及重複 slot。離線結果只證明其檢查範圍。

真實下載、download-check、completion、混合附件 chooser、跨 Session 成功下載與成功恢復均須保留 NOT_RUN，直到後續以手冊中的同一正式日常 Prompt、有效前景與真實原件確認。不增加 Acceptance／E2E 角色入口，不要求人工逐項判斷。
