# LINE 相簿備份名稱與分層計畫

## 目標與決策

新備份使用 `備份根目錄／群組名稱／相簿名稱／相簿名稱_序號.副檔名`。群組及相簿名稱採用交接畫面 OCR 結果；辨識錯誤可由使用者以校正工具修正，完全讀不到時才詢問使用者。照片依下載後的原始檔名排序，由 `001` 起編號，保留原副檔名；超過 999 張時序號加寬。名稱只作顯示，不作群組或相簿的身分判定。

規則只套用於新備份；既有照片、目的地與歷史完成事實保留。使用者指定不對本計畫做獨立 review；資料變更風險仍要求實作後的獨立驗收。沒有可用獨立驗收者時如實保留未完成關卡。

## 實作範圍

- 保留現有備份根目錄與其 `backup-records`，在根目錄下以可辨識的群組名稱與相簿名稱建立照片目錄。保留本地群組、相簿和 attempt 身分；同名衝突使用可讀的區分編號，不覆寫。恢復使用新的有意義空白目錄並保留舊 attempt。
- 在有效交接中由 Agent 擷取名稱，沿用現有離線 OCR；名稱與來源存在私有紀錄。既有交接、盤點及視覺身分判斷維持獨立，不以中文名稱、OCR 或路徑推定同一列表或相簿。
- 下載確定完成且清單穩定後，依原始檔名排序並改名，保存原名、新名與逐檔 SHA-256 對照；完成後重新執行既有數量、穩定性、非空、SHA-256 與 ImageIO 完整解碼驗證，才追加完成紀錄。
- 提供不需手填 JSON 的群組／相簿名稱校正工具。先核對受影響的完成紀錄和照片，改名後重新驗證、追加可追溯對應；群組校正涵蓋其下全部受影響完成相簿。不得改寫原完成事件或把歷史照片納入新規則。
- 改名與校正須持久記錄進度、可安全接續，且防止覆寫、路徑逃逸及身份錯配。中斷、目標衝突、未知派送、檔案異動或狀態無法唯一判定時停止，不重送、不覆寫；不得用新空目錄或重置紀錄規避未知結果。
- 同步更新日常 Skill、參考文件、使用手冊和必要測試；實作細節、許可路徑、驗證與交接界限見 [handoff.md](handoff.md)。

## 驗證與關卡

- 以隔離測試資料涵蓋分層、名稱來源、原始檔名排序、不同副檔名、非法字元、同名碰撞、恢復、舊紀錄相容、校正與中斷恢復；驗證衝突或異動時不覆寫、不重送、不誤認身分。
- 執行 `PYTHONPATH=src /usr/bin/python3 -B -m unittest discover -s tests -p test_daily_records.py` 與實際新增的必要回歸；如實記錄命令、退出碼及環境。
- 由未參與實作的審查者獨立驗收合併結果；不可用作者自評替代。日常簿記、檔案驗證、獨立驗收和實機 E2E 分開報告。
- 實機 LINE 多本備份及跨 session 恢復只在另有真實任務授權和有效前景交接時執行；離線測試不得宣稱實機通過。

## 邊界

這是人工計畫與交接，不是已退役 controller 編譯、schema 驗證或正式 AUTO 證據。計畫文件、測試或交接本身不授權 LINE GUI、Save All、真實照片搬移或校正；任何真實資料操作須以使用者對具體資料的授權為準。實作期間保留原有 dirty／untracked 工作與私人資料，禁止提交照片、私人名稱、原始證據、憑證或 grants。
