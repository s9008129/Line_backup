Skill 啟動必讀 active-task 與 history-index；找不到原 state 目錄不再誤判空帳。README、使用中的 references 與 AGENTS 已收斂至日常產品，原規範留在封存；舊正式 AUTO 研究須另定版本與有界範圍，不從封存直接重播。

`.gitignore` 移除已退役路徑的細碎規則，保留本機設定、照片、backup-records、任務／私有證據、舊私人設定及 Python bytecode 的排除，新增兩類隔離測試暫存目錄。提交前另以 `git check-ignore --no-index` 驗證私有資料被排除、應提交程式／文件未被忽略。
