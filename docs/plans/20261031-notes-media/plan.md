## Agent 流程與恢復

1. 查全部記事本帳本與當前任務，再核對列表。證明新列表且無缺損歷史/候選歧義時自動初始化，不重索既有授權。
2. 頂到底重疊盤點貼文，再逐篇核對附件。縮圖、更多與檢視器序號交叉確認；不可假設單一 viewer 總數等於整篇全部媒體。
3. 一次一項：先持久保存並讀回 intent、新空白暫存目錄與禁止重送紀錄，才開下載。確認另存視窗出處、完整路徑及檔名讀回後儲存一次。下載按鈕與 chooser 確認分開記錄，工具逾時不推論未派送。
4. 穩定檔案、非空、SHA-256、內容解碼核對後，持久記錄命名/發布交易，以不可覆寫方式發布編號檔，completion 保存並讀回。命名中斷接續交易，不重下。
5. 當次可靠控制項返回並確認原列表；每次輸入後重新觀察，不用舊座標、錄影座標或猜 Escape/Command-W。popup 漏在 app-bound 外時依既有可用觀察與映射方法補證據，不盲點。
6. 最後重新對帳；入口、盤點、每篇完成/遇阻及總結主動回報。

已完成不重下；整篇完成目錄缺席保留完成、標示 LOCAL_MISSING，不要求外接硬碟在線。目錄仍存在卻部分缺檔/hash或身分漂移/symlink，停止新派送。UNKNOWN、活動下載、未完成命名不因照片缺席解鎖。

## 實作切片與驗證

第一切片以合成兩照片一影片走通初始化→盤點→intent→結果→驗證→completion→新 Session 查詢跳過；不操作 LINE。Owner 已免除切片獨立審查，完成必要檢查後可在同範圍繼續。

Implementer 負責：CLI整合、事件完整性/讀回、重送拒絕、UNKNOWN調和、命名中斷、跨列表隔離、缺帳本/索引毀損、照片區移除後完成不解鎖、部分缺檔/hash/symlink保護、來源重排與新增對帳。

照片沿用 ImageIO 完整像素解碼；不支援格式保留原檔，列未驗證，不降標準。影片使用成對 /opt/homebrew/bin/ffmpeg 與 ffprobe（規劃時均7.1.1），啟動記錄版本/工具hash。probe檢查有效影像串流，完整讀取及解碼所有影像/音訊至EOF；非零退出、截斷/解碼錯誤或無完整解碼證據不得完成。長影片不套相簿固定120秒限制，等待須回報進度；中止仍保留未驗證。穩定性與hash於驗證前後核對。不得聲稱等同服務端原始位元。

合成測試涵蓋正常有聲/無聲影片、截斷、解碼失敗、無有效影像、長影片等待；保存實際exit code。執行既有 daily/permanent records 必要回歸、Skill格式/引用與 git diff --check。

真實GUI場景待 Owner 另行授權：多篇切換、照片/影片及混合附件、跨Session接續、增刪重排、失效及前景中斷。日常試用由Owner確認，不強制正式獨立acceptance；未實測場景必須NOT_RUN，不以離線測試代替。
