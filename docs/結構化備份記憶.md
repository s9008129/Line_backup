# 日常備份的結構化記憶

`Line_backup` 是唯一核心目錄。日常備份使用本專案的 Skill、程式、JSON 記憶與照片，啟動／接續不查找封存、外層舊目錄或 Git 歷史。穩定操作方法由 Skill 與程式維護；開發歷程留在 Git。

## 記憶放在哪裡

```text
Line_backup/
  backup-records/                  永久保留，不放照片
    index.json                     帳本位置登錄，不存完成計數
    <local_group_id>/
      group.json                   列表身分與原始綁定
      events/*.json                追加式盤點、操作、完成與目的地綁定
      memory-anchors/*.json        匯入記憶校驗
  backup/<相簿目錄>/               照片，可由 Owner 搬走後刪除
  .local/line-backup/               最近任務入口、必要私有證據及工具
```

先列全部帳本，再讀已核對列表；`RECORDS_ROOT` 由 Agent 從結果取得，不要求 Owner 提供 UUID。下列查詢不操作 LINE、不新增備份事件，也不要求照片 root 存在：

```sh
PYTHONPATH=src /usr/bin/python3 -B -m line_backup_batch.daily groups
PYTHONPATH=src /usr/bin/python3 -B -m line_backup_batch.daily memory --records-root "$RECORDS_ROOT"
PYTHONPATH=src /usr/bin/python3 -B -m line_backup_batch.daily summary --records-root "$RECORDS_ROOT"
```

`memory` 輸出為 `line-backup-memory/v1`：`albums` 是逐本身分、狀態、attempt 與 completion；`history` 是已評估歷史；`legacy_albums` 是尚未可靠對應列表的提示；`coverage` 明示涵蓋範圍。這些只是投影，各帳本的事件是唯一狀態來源。`.local/line-backup/active-task.json` 只定位最近任務，不能取代全帳本查詢。

完成事實與本機照片可用性分開：整本完成目錄缺席仍保留完成及禁止重下，不要求硬碟在線或登記歸檔；仍存在但部分缺檔、內容／身分／中繼資料異常或 symlink 時保護原件並停止新派送。外部副本未經驗證，不能把本機缺席報成硬碟備份完整。UNKNOWN、活動下載與未完成命名交易不因照片消失解鎖。

舊照片樹內的帳本使用 `daily migrate-records --root <舊照片 root>` 安全複製至永久區並讀回，原件保留、舊入口拒絕寫入；可用 `--records-root <collection>` 指定受支援位置。新一批照片目的地由 fresh bind 後的 `daily destination` 追加綁定，不改寫舊 completion。完整步驟集中在 [備份與恢復](../.agents/skills/line-album-agent-cua/references/backup-and-resume.md#每次啟動都自動找回任務)。

保留專案 `backup-records/` 與 `.local/line-backup/`，刪除照片 `backup/` 不會刪除它們。這項設計不涵蓋整個專案或磁碟遺失後的還原。

## 如何切斷來源依賴

新的 `history` 匯入只在寫入時查核本專案的來源，將狀態判定、來源 digest、完成所需 manifest／ImageIO 結構化結果，或排除決定摘要內嵌進事件。後續讀記憶不重開匯入來源。來源缺少或身分不合者維持受保護；UNKNOWN 不升格為未派送。

既有舊格式 history 用一次性 `memory-import` 追加內嵌快照，保留原事件；來源缺失時記為受保護，不重新下載或補造完成。此為離線資料整理，不需要前景交接，也不產生 GUI 權限。

每個結構化 history／memory 匯入事件另存一份不可覆寫的 SHA-256 校驗紀錄。讀取核對內容及集合，末筆記憶單獨被改寫／移除也會停止。寫入中斷而缺校驗紀錄同樣停止。這是本機一致性檢查，不是簽章，也不保證防止有權同時修改事件與校驗檔的人。

工具拒絕本專案以外的目的地 root、CLI 輸入與證據引用；本機編譯工具也放在專案內。這個路徑限制不是 OS sandbox 或網路隔離。
