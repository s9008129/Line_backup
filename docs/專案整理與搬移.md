# 專案整理與搬移紀錄

日期：2026-10-25

本次依 Owner 凍結的 allowlist，將部分可重建快取、Finder metadata 及舊根目錄 Markdown 從活躍工作目錄移至外部封存區。外部完整快照保持原樣；來源和快照在搬移前逐檔比對型別、大小、SHA-256 與 symlink target，搬移後再逐項驗證。

## 結果

- 搬移 63 個頂層項目、53,983 個檔案系統節點，共 3,662,301,514 bytes（約 3.41 GiB）。
- 分類：18 個 Swift build/cache 目錄、7 個 Python bytecode cache、11 個 `.DS_Store`、27 篇舊 Markdown。
- 使用同磁碟 rename，目的地保留原相對路徑於外部封存的 `removed-from-active/`。完整快照仍留在封存的 `worktree/`。
- 1,275 項 preservation baseline 搬移前後均 PASS；原有三項 dirty 檔案及 `image_decode`、`rev28ctl`、`rev28probe` 的雜湊未變。
- 沒有刪除檔案。測試未執行，因本次變更只涉及封存搬移，沒有修改產品程式。

## 邊界與重播

照片、歷史原始 evidence、grant、ledger、state、正式 runtime/bin、`rev28/.build`、`src/`、`tests/` 和其他未列入 allowlist 的內容均保留於原位。部分歷史 task 的程式或 manifest 曾引用這些建置產物；需要重播時，請從外部封存還原對應相對路徑，再依原任務契約核對版本。不能把原活躍路徑仍可執行視為已驗證。

逐項 SHA-256、大小、型別、連結目標及搬移狀態記錄於 `harness-development/foreground-album-repair-20261025/private/cleanup-20261025-active-root-prune/` 的 `pre-move-manifest.json` 與 `receipt.json`。外部封存位置由該 task package 的 `archive-location.txt` 記錄。

## 後續狀態：等待 Owner 決定永久刪除

本次只把核准項目移入外部封存，**沒有永久刪除**。Owner 決定前，外部完整 `worktree/` 快照及 `removed-from-active/` 副本均保留。63 項精確清單、各項節點與位元組資訊見 `harness-development/foreground-album-repair-20261025/public/cleanup-allowlist.csv`；按 A/B/C 風險分級及永久刪除前重驗條件見 `docs/封存資料_建議刪除清單.md`。

封存重驗結果：來源與 worktree 的逐節點比對 PASS；搬移後 removed-from-active 與 worktree 再比對 PASS；1,275 項 preservation baseline 前後 PASS。原有 dirty 檔案及核心 runtime binary 雜湊不變。建置快取舊路徑不再位於活躍工作目錄，若需精確歷史重播，需由保留的封存還原。封存使用 APFS clone，未來刪除一份 clone 不保證回收等量實體空間。

這是檔案整理紀錄，不是產品測試；未執行程式或 LINE E2E 測試。最終產品測試狀態由根代理另線合併回報。
