# LINE 相簿備份使用手冊

你人工開好要處理的 LINE 相簿列表、首次指定照片保存位置，再把前景交給 Agent。預設就是下載這份列表所有尚未備份、未排除的相簿；有舊進度就自動接續，不用選模式或提示「接續」。不需要輸入群組名稱。

## 開始前

- 使用已登入 LINE、具有原生 Mac Computer Use 的 Codex Session；只有終端機或瀏覽器工具不能代替它。
- 準備容量充足的保存位置，並告訴 Agent 舊照片與完成紀錄在哪裡。新目錄不代表從未備份。
- 操作期間讓 Agent 使用 LINE 前景；需要使用電腦時先請它停止新增操作、保存進度。Agent 不自行啟動或尋找另一個列表。

在專案資料夾啟動 Codex，貼上下方提示詞。提示詞是啟動方式；具體操作方法集中在 [專屬 Skill](../.agents/skills/line-album-agent-cua/SKILL.md)。

## 可重複使用的啟動提示詞

第一次在 BACKUP_ROOT 填保存位置；之後留空即可自動沿用上次任務，也可填同一位置。Agent 必須每次自行查明前次是否完成或中斷，再繼續，不能要求你記得做到哪裡。完整盤點是它下載前必做的工作，不需要另一道指令。

```text
BACKUP_ROOT=
EXCLUSIONS=[]

請使用本專案 $line-album-agent-cua，完成我人工開啟並交到前景的 LINE 相簿列表中，所有尚未備份、未排除的相簿。由 AI Agent 判讀並操作，不新增控制器或授權框架。

每次啟動都先自動讀取上次任務入口、完成與操作紀錄及實際檔案，確認前次是否已完成、仍在下載、待驗證、已中斷或結果未知，再自行安排下一步。BACKUP_ROOT 留空時沿用已確認的原任務；真的找不到保存位置或任務對應不明才問我，不要求我填模式、說接續或判斷下載結果。

我會人工開好正確列表並交出前景；交接前不要啟動或操作 LINE。交接後，本任務授權你自主觀察、捲動、開啟相簿、返回列表、下載至指定位置的新空白目錄、驗證及保存進度，直到這份列表全部符合資格的相簿完成。

先查舊完成、排除與中斷資料，再完整盤點列表、保存總本數、逐本狀態與有序清單，接著自動下載，不停在盤點回報等待我另下指令。已有清單時核對當下內容，必要時更新。不要以群組名稱或中文 OCR 辨識群組；疑似開到另一列表才向我釐清。

本任務也授權你自動相簿級恢復：已完成的跳過；仍在下載的先觀察；已下載但未驗證的先驗證；確認已停止且未完成的一本，保留原檔並自行改用另一個新空白目錄恢復，不必逐本再問我要不要接續。結果未知先自行查證，無法解決才問具體問題；不盲目重送，也不改寫舊結果解鎖。授權只限這項任務及已確認列表／位置，撤回即停止。

一次只處理一本，操作前保存紀錄，儲存全部只送一次。逐檔核對數量、SHA-256 與 ImageIO 完整解碼，完成紀錄寫後讀回再繼續下一本。首次任務保存上次任務入口，每本完成即保存進度；下次啟動自行讀取，不只靠聊天記憶。

不發訊息、刪除、分享、覆寫舊照片或變更正式完成事實；不操作其他列表。不 push、merge 或啟動雲端 CI。前景中斷、身分不明、儲存位置不符或工具拒絕時，保存進度並用白話告訴我需要處理的一件事。

定期回報總本數、已完成、排除、待下載、先前未完成、未知與受保護歷史，以及已驗證張數。只有列表確實看完、逐本對上且待辦與未知均為零，才回報這次全部完成。不要把未實測的能力寫成成功。
```

這份範本只有你實際提交為備份任務後才提供所述授權；討論或修改它不是執行。只審查 Skill 時不開 LINE。首次未填位置且找不到已確認任務時，Agent 只問真正缺少的保存位置。

## 中斷後怎麼繼續

照常啟動 Agent 並交回原列表前景即可。它必須自己讀回上次任務與實際檔案，判斷前次狀態並接續，不要求你填 RESUME 或提醒它。

已完成的不重下；還在下載的先觀察；已下載完但未驗證的先驗證現有檔案；確定停止且未完成的，在原任務授權內自行保留舊檔、用新目錄恢復該本。採相簿級恢復，不承諾 LINE 能只補缺少的照片。

若前次到底有沒有開始下載仍不清楚，Agent 會先查紀錄與檔案，不因你再次啟動就自動重送。

若 Agent 整個程序已被關閉，仍需重新啟動它；Skill 不會自己喚醒已關閉的程式。但重新啟動後的狀態判斷與接續是 Agent 的責任，不是你再選另一個模式。

## 怎麼知道全部完成

盤點清單的總本數應等於「已完成＋已排除＋待下載＋先前未完成＋未知＋受保護歷史」。已完成與排除以外均為零，並有從頂到底的列表覆蓋及逐本驗證證據，才算這次處理完成。這不保證日後新增照片也已備份。

進度與完成紀錄要保存在正式保存位置的 `backup-records`，照片放在各次的新相簿目錄。舊資料來源另有位置時保留連結；不會因這份手冊自動搬移照片。

## 目前仍要驗證的地方

已有真實列表捲動、選單、儲存位置選擇與完整檔案驗證經驗。這輪整理了方法，沒有操作 LINE 或下載；新版完整盤點、跨 Session 接續及相簿級恢復仍需另外安排實測。

獨立選單視窗能否觀察，要看當次工具支援。歷史成功不保證每個 Session 都有相同能力；缺工具時先停下說明，不盲點。

日常 Agent 備份不等於舊正式 AUTO 驗收。舊研究資料另外保存，不作日常使用者的額外設定表單；既有程式若拒絕，Agent 仍不會繞過它。
