# 用 Prompt 啟動 LINE 相簿備份

在本專案的 Agent 對話貼上下方 Prompt，人工開好指定的 LINE 相簿列表，再交出前景。Agent 應自行查舊進度、盤點、逐本執行「儲存全部」、驗證及保存紀錄，直到這份列表的合格相簿完成；不需要逐本下令或在盤點後再說「開始下載」。

## 1. 填寫 Prompt

| 欄位 | 怎麼填 |
|---|---|
| `BACKUP_ROOT` | 首次填照片保存位置的完整絕對路徑；沿用同一任務時可留空，由 Agent 讀取已確認的原位置。自行查證後仍無法唯一對應才詢問。 |
| `EXCLUSIONS` | 沒有新增排除就填 `[]`；需要排除時，描述相簿日期、張數及可區分的封面／內容，歧義由 Agent 再核對。`[]` 不解除既有排除，也不允許重下已完成相簿。 |

本專案已確認的保存位置為 `/Users/hsiaojohnny/Documents/ChatGPT/Line_backup/backups`；沿用時可填這個位置或留空。若要處理另一份列表或更換位置，請明說，讓 Agent 先確認任務對應。不需要提供群組中文名稱、座標、API 或內部 ID。

### 可直接貼用的啟動 Prompt

首次與下次啟動都使用這一份 Prompt。提交它代表授權所述備份工作；只討論或修改範本不代表執行。

```text
BACKUP_ROOT=
EXCLUSIONS=[]

請使用本專案 $line-album-agent-cua，完成我人工開啟並交到前景的 LINE 相簿列表中，所有尚未備份、未排除的相簿。由 AI Agent 判讀並操作，不新增控制器或授權框架。

每次啟動都先自動讀取上次任務入口、完成與操作紀錄及實際檔案，確認前次是否已完成、仍在下載、待驗證、已中斷或結果未知，再自行安排下一步。BACKUP_ROOT 留空時沿用已確認的原任務；真的找不到保存位置或任務對應不明才問我，不要求我填模式、說接續或判斷下載結果。

我會人工開好正確列表並明確交出前景；交接前不要啟動或操作 LINE。交接後，我授權你自主觀察、捲動、開啟相簿、返回列表，對每一本符合資格的相簿執行原生「儲存全部」，下載至指定位置下各自的新空白目錄、驗證及保存進度，直到這份列表全部符合資格的相簿完成。不必逐本再問我是否儲存全部。

先查舊完成、排除與中斷資料，再完整盤點列表、保存總本數、逐本狀態與有序清單，接著自動下載，不停在盤點回報等待我另下指令。已有清單時核對當下內容，必要時更新。不要以群組名稱或中文 OCR 辨識群組；疑似開到另一列表才向我釐清。

本任務也授權你自動相簿級恢復：已完成的跳過；仍在下載的先觀察；已下載但未驗證的先驗證；確認已停止且未完成的一本，保留原檔並自行改用另一個新空白目錄恢復，不必逐本再問我要不要接續。結果未知先自行查證，無法解決才問具體問題；不盲目重送，也不改寫舊結果解鎖。授權只限這項任務及已確認列表／位置，撤回即停止。

一次只處理一本。每次嘗試點儲存全部前，保存並讀回操作紀錄及新空白目的地；每個 attempt 的儲存全部最多送一次，核對資料夾選擇器實際路徑後確認一次。逐檔核對預期數量、非空、檔案穩定性、SHA-256 與 ImageIO 完整解碼；完成紀錄寫後讀回，自主返回同一列表，以新畫面定位下一本並繼續。首次任務保存上次任務入口，每本完成即保存進度；下次啟動自行讀取，不只靠聊天記憶。

主視窗看不到選單時，先用當次允許的觀察來源補查，確認即時畫面與可靠座標映射後自行操作；不要把觀察缺口當成未獲下載授權。無法可靠定位就保存證據並回報具體缺口，不盲點或使用舊座標。點擊結果未知時先查證，不重點。

不發訊息、刪除、分享、覆寫舊照片或變更正式完成事實；不操作其他列表。不 push、merge 或啟動雲端 CI。前景中斷就停止 GUI 輸入；身分、儲存位置、工具能力或結果有疑義，先在授權內唯讀查證，仍無法解決才保存進度並用白話告訴我需要處理的一件事。不繞過工具拒絕，不要求我手填 JSON。

定期回報總本數、已完成、排除、待下載、先前未完成、未知與受保護歷史，以及已驗證張數。只有列表確實看完、逐本對上，且待下載、先前未完成、未知與受保護歷史均為零，才回報這次全部完成。照片驗證與完成紀錄提交分開說明；不要把文件規範、單本成果或未實測能力寫成整批成功。
```

## 2. 人工開好列表，再交出前景

使用具有原生 Mac Computer Use 的 Agent Session，人工登入 LINE 並開好正確的相簿列表。準備好後，在同一對話送出：

```text
正確的 LINE 相簿列表已開啟，我已交出前景。請依上述任務自主完成。
```

若提交任務 Prompt 時已準備好，也可在該則訊息末尾直接加上這句。交接後讓 Agent 使用前景；不需要補上「請點儲存全部」、提供座標或指定 API。需要使用電腦時，先請 Agent 停止新增操作並保存進度。

## 3. 下次啟動仍使用同一份 Prompt

在本專案重新啟動 Agent，貼上同一份 Prompt，`BACKUP_ROOT` 留空或填原位置，開好原列表後交接前景即可。不需要填 `RESUME`、回想上次做到哪一本或判斷是否下載成功。

Agent 應讀回原紀錄及檔案：完成的跳過、仍下載的觀察、待驗證的先驗證、確定停止且未完成的依原授權恢復。若 Agent 程序已關閉，仍需由你重新啟動；Skill 不會自行喚醒程序。

## Prompt 的授權與完成界限

這份 Prompt 已涵蓋儲存全部與相簿級恢復；你的必要輸入是指定對象、首次保存位置、排除要求及有效前景交接。Agent 負責清單、定位、操作、驗證及狀態判斷。更長的 Prompt 無法補足工具缺少的畫面、座標映射或紀錄提交能力。

現有工具若已寫入明確 `UNKNOWN`，即使後來照片通過唯讀驗證，也可能無法提交完成紀錄。Agent 必須如實回報這兩種結果，不以再次授權、改寫歷史或重新下載解鎖。

前次實機完成一本 51 張的逐檔驗證；新版即時 popup 定位、多本連續處理、跨 Session 接續與中斷恢復仍待實測。完整操作方法見 [專案 Skill](../.agents/skills/line-album-agent-cua/SKILL.md)，根因與驗證界限見 [Skill 優化分析報告](LINE相簿Agent驅動_Skill優化分析與驗證報告.md)。日常備份結果不等於舊正式 AUTO 或獨立 E2E 驗收。
