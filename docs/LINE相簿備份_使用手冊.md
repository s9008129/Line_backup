# 用 Prompt 啟動 LINE 相簿備份

在本專案的 Agent 對話貼上下方 Prompt，人工開好指定的 LINE 相簿列表，再交出前景。Agent 應自行查舊進度、盤點、逐本執行「儲存全部」、驗證及保存紀錄，直到這份列表的合格相簿完成；不需要逐本下令或在盤點後再說「開始下載」。

`Line_backup` 是唯一核心目錄。日常進度來自本專案 `backup-records` 的結構化 JSON 與照片；開發歷程留在 Git，不是備份記憶，也不要求保留外層舊資料。

## 1. 填寫 Prompt

| 欄位 | 怎麼填 |
|---|---|
| `BACKUP_ROOT` | 可留空，預設使用目前專案根目錄的 `backups/`；要用其他專案內位置時填完整絕對路徑。接續仍須核對原任務與位置綁定。 |
| `EXCLUSIONS` | 沒有新增排除就填 `[]`；需要排除時，描述相簿日期、張數及可區分的封面／內容，歧義由 Agent 再核對。`[]` 不解除既有排除，也不允許重下已完成相簿。 |

本工作區目前的預設保存位置為 `/Users/hsiaojohnny/dev/Line_backup/backups`。專案未來搬移時，以當前專案根目錄下的 `backups/` 為準。若既有任務紀錄仍綁定舊位置或搬移後檔案身分改變，Agent 必須保留原件並停止接續，先安全對帳；不會直接改寫舊紀錄或重新下載。若要處理另一份列表或更換位置，請明說，讓 Agent 先確認任務對應。不需要提供群組中文名稱、座標、API 或內部 ID。

### 可直接貼用的啟動 Prompt

首次與下次啟動都使用這一份 Prompt。提交它代表授權所述備份工作；只討論或修改範本不代表執行。

```text
BACKUP_ROOT=
EXCLUSIONS=[]

請使用本專案 $line-album-agent-cua，完成我人工開啟並交到前景的 LINE 相簿列表中，所有尚未備份、未排除的相簿。由 AI Agent 判讀並操作，不新增控制器或授權框架。

以 Line_backup 為唯一核心目錄。BACKUP_ROOT 留空時，預設使用目前專案根目錄下的 backups。每次啟動都先自動讀取本專案上次任務入口、daily memory 的結構化記憶、完成與操作紀錄及實際檔案，確認前次是否已完成、仍在下載、待驗證、已中斷或結果未知，再自行安排下一步。不要查找封存、外層舊資料或 Git 歷史作為備份記憶；若搬移導致舊任務路徑或目錄身分不符，保留原件並停止接續，不改寫紀錄或重下載。真的找不到保存位置或任務對應不明才問我，不要求我填模式、說接續或判斷下載結果。

我會人工開好正確列表並明確交出前景；交接前不要啟動或操作 LINE。交接後，我授權你自主觀察、捲動、開啟相簿、返回列表，對每一本符合資格的相簿執行原生「儲存全部」，下載至 `BACKUP_ROOT/<群組名稱>/<相簿名稱>/` 的新空白目錄、完成 `<相簿名稱>_001.<原副檔名>` 命名與驗證，並保存進度，直到這份列表全部符合資格的相簿完成。不必逐本再問我是否儲存全部。

先查舊完成、排除與中斷資料，再完整盤點列表、保存總本數、逐本狀態與有序清單，接著自動下載，不停在盤點回報等待我另下指令。已有清單時核對當下內容，必要時更新。不要以群組名稱或中文 OCR 辨識群組；疑似開到另一列表才向我釐清。

本任務也授權你自動相簿級恢復：已完成的跳過；仍在下載的先觀察；已下載但未驗證的先驗證；確認已停止且未完成的一本，保留原檔並自行改用另一個新空白目錄恢復，不必逐本再問我要不要接續。結果未知先自行查證，無法解決才問具體問題；不盲目重送，也不改寫舊結果解鎖。授權只限這項任務及已確認列表／位置，撤回即停止。

一次只處理一本。同一列表先從交接畫面取得群組顯示名並保存一次；每本經視覺身分確認後，再取得相簿顯示名並保存。名稱只用於顯示及目錄，不作身分判定；完全讀不到名稱時才問我。接著以私有 evidence 記錄該本 `detail`，再用 `intent` 建立並讀回具名新空白目的地；每個 attempt 的儲存全部最多送一次，核對資料夾選擇器完整路徑後確認一次。下載完成後，先以 direct `outcome` 記錄唯一已知的 `DOWNLOAD_FINISHED` 與 evidence，再用 direct `verify --attempt-id` 依原始檔名排序完成持久改名與逐檔數量、非空、穩定性、SHA-256、ImageIO 完整解碼驗證，不由 Finder 手動改名；完成紀錄寫後讀回，自主返回同一列表，以新畫面定位下一本並繼續。命名中斷用 `resume-naming`，不重送 Save All。首次任務保存上次任務入口，每本完成即保存進度；下次啟動自行讀取，不只靠聊天記憶。

主視窗看不到選單時，先用當次允許的觀察來源補查，確認即時畫面與可靠座標映射後自行操作；不要把觀察缺口當成未獲下載授權。無法可靠定位就保存證據並回報具體缺口，不盲點或使用舊座標。點擊結果未知時先查證，不重點。

不發訊息、刪除、分享、覆寫舊照片或變更正式完成事實；不操作其他列表。不 push、merge 或啟動雲端 CI。前景中斷就停止 GUI 輸入；身分、儲存位置、工具能力或結果有疑義，先在授權內唯讀查證，仍無法解決才保存進度並用白話告訴我需要處理的一件事。不繞過工具拒絕，不要求我手填 JSON。

定期回報總本數、已完成、排除、待下載、先前未完成、未知與受保護歷史，以及已驗證張數。只有列表確實看完、逐本對上，且待下載、先前未完成、未知與受保護歷史均為零，才回報這次全部完成。照片驗證與完成紀錄提交分開說明；不要把文件規範、單本成果或未實測能力寫成整批成功。
```

## 2. 人工開好列表，再交出前景

使用具有原生 Mac Computer Use 的 Agent Session，人工登入 LINE 並開好正確的相簿列表。準備好後，在同一對話送出：

```text
正確的 LINE 相簿列表已開啟，我已交出前景。請依上述任務自主完成。
```

若提交任務 Prompt 時已準備好，也可在該則訊息末尾直接加上這句。交接後讓 Agent 使用前景；不需要補上「請點儲存全部」、提供座標或指定 API。需要使用電腦時，先請 Agent 停止新增操作並保存進度。

## 3. 下次啟動仍使用同一份 Prompt

在本專案重新啟動 Agent，貼上同一份 Prompt；使用預設位置時 `BACKUP_ROOT` 留空，使用已確認的其他專案內位置時填該位置，再開好原列表並交接前景。不需要填 `RESUME`、回想上次做到哪一本或判斷是否下載成功；搬移後的舊綁定仍須先安全對帳。

Agent 應讀回原紀錄及檔案：完成的跳過、仍下載的觀察、待驗證的先驗證、確定停止且未完成的依原授權恢復。若 Agent 程序已關閉，仍需由你重新啟動；Skill 不會自行喚醒程序。

## 4. 名稱校正與命名中斷

新備份會放在 `BACKUP_ROOT/<群組目錄名>/<相簿目錄名>/`，照片為 `<相簿目錄名>_001.<原副檔名>`。名稱只供顯示及路徑使用；同一列表與相簿仍以本地身分和視覺證據判定。同名不同實體會使用 ` (2)`、` (3)`，恢復使用 ` (恢復 N)`；既有 `albums/<UUID>` 與舊照片不遷移。名稱完全讀不到時 Agent 才問你，不能默默建立舊格式新備份。

若名稱有錯字，直接請 Agent 用校正工具，不要自己在 Finder 改名。Agent 先用 `memory` 找到 `album_key`，再以單本 `correct-album-name` 同步修改資料夾與照片前綴；群組錯字用 `correct-group-name` 涵蓋該組已完成的新格式相簿。群組內仍有未完成、未知、舊格式或外來項目、相簿內有額外檔案、符號連結，或來源檔案在計畫後變動時，工具會停止，不會只改一部分或覆寫目標。整個命名與校正流程都使用 direct CLI 參數，不需要你提供或編輯 JSON。若命名或校正中斷，Agent 執行 `resume-naming` 並重驗，不重送下載：

```sh
PYTHONPATH=src /usr/bin/python3 -B -m line_backup_batch.daily resume-naming \
  --root "$BACKUP_ROOT" --decoder "$DECODER" --decoder-sha256 "$DECODER_SHA256"
```

所有 daily CLI 的業務層成功以 exit 0、業務拒絕以 exit 4 回傳 JSON 簿記結果，固定包含 `dispatch_authorized=false`，不授予 LINE GUI 或 Save All 權限；參數語法／必填欄位錯誤會在執行前以 exit 2 拒絕，不產生 JSON 或紀錄變更。實際下載仍須符合本次任務授權及前景交接。

## Prompt 的授權與完成界限

這份 Prompt 已涵蓋儲存全部與相簿級恢復；你的必要輸入是指定對象、必要時指定非預設保存位置、排除要求及有效前景交接。Agent 負責清單、定位、操作、驗證及狀態判斷。更長的 Prompt 無法補足工具缺少的畫面、座標映射或紀錄提交能力。

現有工具若已寫入明確 `UNKNOWN`，即使後來照片通過唯讀驗證，也可能無法提交完成紀錄。Agent 必須如實回報這兩種結果，不以再次授權、改寫歷史或重新下載解鎖。

前次實機完成一本 51 張的逐檔驗證；新版即時 popup 定位、多本連續處理、跨 Session 接續與中斷恢復仍待實測。完整操作方法見 [專案 Skill](../.agents/skills/line-album-agent-cua/SKILL.md)，記憶位置與驗證界限見 [結構化備份記憶](結構化備份記憶.md)。日常備份結果不等於舊正式 AUTO 或獨立 E2E 驗收。
